# Product Discovery V0.4 — Curriculum & Mathematics Intelligence

**Status:** LOCKED  
**Locked:** 4 September 2026

## 1. Curriculum scope

MVP is **Kurikulum Merdeka first**.

Architecture must remain versioned and extensible for future curriculum variants.

Conceptually:

```text
Curriculum
└── Kurikulum Merdeka
    └── Version
        └── Subject
            └── Phase
```

## 2. Curriculum authority

Curriculum claims must be grounded in controlled curriculum data derived from official government sources and then:

```text
OFFICIAL SOURCE
      ↓
STRUCTURED
      ↓
AI-ASSISTED MAPPING
      ↓
HUMAN REVIEW
      ↓
PUBLISHED
```

The model's own memory is not the curriculum authority.

## 3. Relevant education phases

Initial product scope includes:

- Grade 4 SD
- Grade 5 SD
- Grade 6 SD
- Grade 7 SMP
- Grade 8 SMP
- Grade 9 SMP

Curriculum data must map grade/class context into the relevant curriculum phase.

## 4. Curriculum model

Curriculum is modeled beyond a flat topic list.

```text
CURRICULUM
    ↓
PHASE
    ↓
DOMAIN / ELEMENT
    ↓
LEARNING OUTCOME
    ↓
TOPIC
    ↓
CONCEPT
    ├── prerequisites
    ├── representations
    ├── misconceptions
    ├── difficulty
    └── assessment metadata
```

## 5. Teacher authority

Teachers may request content outside the selected curriculum context.

The system should:

1. privately warn the teacher;
2. explain that it is outside the selected scope;
3. allow the teacher to proceed.

The curriculum is a teaching guardrail, not a hard prison.

## 6. Private curriculum suggestions

The AI may privately suggest:

- prerequisite review;
- related concept;
- scope mismatch;
- sequencing adjustment.

Teacher decides whether to use it.

## 7. Teaching approach

AI should support a richer learning progression rather than only produce answers.

Default pedagogical direction:

```text
UNDERSTAND
   ↓
VISUALIZE
   ↓
PRACTICE / APPLY
   ↓
REFLECT
```

## 8. Difficulty model

Difficulty is multidimensional internally.

Example dimensions:

- conceptual complexity;
- computational complexity;
- number of steps;
- language complexity;
- abstraction.

Teacher UI may still show a simplified scale:

- Mudah
- Sedang
- Sulit

“Buat lebih sulit” should increase difficulty gradually within the current concept boundary unless the teacher explicitly requests a new/advanced concept.

## 9. QuestionPackage

A generated question should ideally produce one validated package:

```text
QuestionPackage
├── Question
├── Correct Answer
├── Solution Steps
├── Hint Level 1
├── Hint Level 2
├── Explanation
├── Difficulty
├── Curriculum Mapping
└── Visual Representation
```

## 10. Hint ladder

Hints should progressively help without immediately leaking the answer.

Example progression:

```text
Hint 1
↓
Hint 2
↓
Solution Step 1
↓
Solution Step 2
↓
Answer
```

## 11. Misconception intelligence

A simple misconception capability is part of MVP.

The system should try to identify common mathematical error patterns rather than only return:

- correct;
- wrong.

Example:

```text
1/2 + 1/3 = 2/5
```

Possible detected misconception:

> adding numerators and denominators directly.

The result should primarily assist the teacher.

## 12. Representation engine

Concepts may define preferred representations.

Examples:

### Fractions

- fraction bar;
- circle model;
- symbolic notation;
- later: number line.

### Linear equations

- symbolic equation;
- balance model;
- step-by-step transformation.

### Geometry

- 2D shapes;
- measurements;
- angles;
- labels.

Default behavior:

1. AI selects one most appropriate representation.
2. Teacher can say: “Tampilkan dengan cara lain.”
3. System replaces/adds another representation.

## 13. Math generation and validation

LLM may generate:

- story context;
- wording;
- examples;
- explanations.

Whenever mathematics is deterministic, a math engine validates:

- answer;
- equivalence;
- solution steps;
- mathematical consistency.

Invalid content must be rejected, repaired, or regenerated before reaching the classroom display.

## 14. Prototype vertical slices

Initial intelligence prototype:

### Grade 5

**Fractions**

Potential concept slice:

- fraction meaning;
- equivalent fractions;
- comparison;
- addition;
- subtraction.

### Grade 7

**Basic Algebra / Linear Equations**

Potential concept slice:

- variable;
- algebraic expression;
- equation;
- simple linear equation.

These two slices are used to prove the architecture before expanding content breadth.

## 15. Initial mathematics MVP scope

After prototype validation:

- arithmetic;
- fractions;
- decimals;
- percentages;
- basic algebra;
- linear equations;
- basic geometry;
- perimeter;
- area;
- basic angles.

Explicitly not an initial target:

- calculus;
- advanced trigonometry;
- matrices;
- complex numbers;
- advanced symbolic proof.

## 16. Curriculum manual override

Teacher lesson configuration includes curriculum alignment.

Example:

```text
[✓] Sesuaikan dengan kurikulum
```

The teacher may turn it off.

Teacher authority remains final.

## 17. Curriculum versioning

Every lesson must reference a curriculum version rather than only a generic curriculum name.

This supports:

- reproducibility;
- policy changes;
- historical lessons;
- future curriculum updates.
